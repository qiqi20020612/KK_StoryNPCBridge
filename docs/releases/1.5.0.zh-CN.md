# KK_StoryNPCBridge 1.5.0

[English](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.5.0/docs/releases/1.5.0.md) | 简体中文

相对于 **1.4.0** 的更新。

## 新增

- `play_adv_motion`：在桥接角色已就绪的 TalkScene 中独立执行原生 `ADV.CharaMotion`。支持第 0 层的状态／控制器资源、原生 IK 和摇晃／身体修正数据，可设置 0.1–30 秒原生等待。复用现有 ADV 演出生命周期，不另建对话系统。
- `adv_motion_catalog`：检查已安装的动作资源，通过实际 Animator 验证匹配状态，并返回可复用的动作对象及完整调用模板。缺失资源、IK／摇晃状态不匹配、依赖其他参演角色的 IK 及不支持的字段，均在执行前拒绝。
- 高级动作复用演出状态、取消及生命周期事件，以 `operation='play_adv_motion'` 标识。完成结果包含实际演出的控制器／片段、IK、物理开关及恢复状态。断线恢复暂停进度且不重放动作；完成、取消和原生执行异常均恢复已捕获的视觉状态。
- 只读的 `actor.clothing`、`clothing_status` 和 `clothing_catalog`，报告漫游及原生对话中的实际穿着栏位类型，并说明无法观测的原因。

## 调整

- 受控 NPC 在原生时间阶段切换时参与游戏的位置和穿着初始化，随后在原生选择的新落点等待。保留控制权／重连预留，上报重定位结果及旧移动、任务、跟随关系的取消。普通玩家换地图不会触发角色重定位。
- 桥接角色进度与行动日志改为**仅在原生故事存档保存成功后写盘**，包括原生自动保存。另存为使用实际目标槽位。属性／表情修改、对话返回、时间切换、控制权交接、定期采样和退出不再独立保存桥接文件；未保存进度在重新载入／退出时丢弃。保存完成及桥接文件失败分别上报事件。
- ADV 回复分页按实际原生字体和文本区域测量，取代固定字数限制。支持中英混排、超长单词、显式换行及受支持的富文本作用域；字体／区域变化后重新排版剩余页。事件提供实际显示文字及布局版本，历史保留完整原文。
- 手动客户端及中英文 API／编号参考补充高级动作、资源目录、恢复机制，以及与轻量 `Animator.Play` 播放的区别。

## 动作支持范围

`play_animation`、动态 `animation_catalog`、普通演出动作、`say`、`say_native` 和原生游戏行动保持原有用途。高级动作仅产生视觉演出，不创建道具、搭档或游戏事件效果。高级动作执行期间触发原生活动，须等待或先取消演出。

高级动作沿用当前镜头与站位，不自动重新构图。坐姿／卧姿或专用事件动作在站立对话机位中可能部分出画，调用方需为这些姿势安排合适的演出环境。

仅开放第 0 层。`OverrideBundle`／`OverrideAsset` 暂不开放：已观察到覆盖控制器被创建，但尚未验证实际片段替换。非零／多层也暂不开放。目录明确标记未穷举全部状态，可提交其他已知状态名进行验证。详见 [API 参数表](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.5.0/API.zh-CN.md#高级原生-adv-动作)。

## 验证

已使用本地游戏引用及锁定的公共编译引用构建，警告按错误处理。实机检查涵盖实际控制器／IK／物理变化与恢复、目录模板调用、非法参数、控制权、原有动画、取消、断线重连、注入原生执行异常、原生对话退出及漫游行为；并对分页、穿着观测和原生时间阶段重定位进行了回归检查。

## 安装

关闭游戏，替换 `BepInEx/plugins/KK_StoryNPCBridge.dll` 后重启。ZIP 包含同一 DLL 的安装路径及 MIT 许可证。下载校验值见 `SHA256SUMS.txt`，不包含游戏或依赖程序集。
