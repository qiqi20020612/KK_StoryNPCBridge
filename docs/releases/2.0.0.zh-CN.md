# KK_StoryNPCBridge 2.0.0

[English](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/releases/2.0.0.md) | 简体中文

相对 **1.5.0** 的更新。Bridge 协议仍为 **2**；原有命令、专属 NPC 身份、原生存档隔离和控制恢复保持兼容。

## H 场景报告

- 增加只读的 `status.hScene` 和 `status.lastHScene`，同时出现在 `list` 和订阅快照中。现有 `AddEvent` 发布 `game_h_started`、`game_h_ended`，每个观测到的原生会话仅发布一次 `game_h_completed`。
- 使用 KKAPI `GameCustomFunctionController` 提供的原生开始／结束对象，报告包含唯一会话、参与者栏位及原生引用身份、游戏时间、模式、实际持续时间、全部 46 个 `HFlag.Count` 字段（含稀疏鼠标交互标志）、原生结束状态及开始／结束／最终结算属性。
- 保留原生统计范围；角色累计属性单独求差，多人场景公共计数不分配给某个角色。普通 NPC、自主单人／女性双人场景及身份未解析的额外男性模型不会冒充 `bridge:main`，也不会将仅存在于上下文的玩家算作参与者。
- 原生结束回调早于最终奖励结算：卸载前冻结统计，H／结果场景退出且正常剧情恢复后再读最终属性。中途退出、重复回调、切档／generation 改变以及缺失／非有限数值均有明确不可用标记。
- 仅追加一个被动的 `HActionBase.SetPlay` postfix，去重记录独立模式的 `Orgasm` 状态进入次数，因为这些模式不更新普通 H 高潮计数。没有重复生命周期 Hook、场景查找轮询、无限历史或新增游戏控制。

中英文文档说明了[字段含义、原生范围、适用模式和不可用情况](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/API.zh-CN.md#只读-h-场景报告)，并提供[完整合成 JSON 报告](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/examples/h-scene-report.json)。

## KKAPI 依赖与代码精简

**官方 KKAPI 1.48.1 或更新版本成为必需依赖。** 请先安装 KK Modding API 及其 ExtensibleSaveFormat 依赖。BepInEx 根据 `marco.kkapi >= 1.48.1` 检查并先加载依赖。带官方补丁的 Party 同样使用 KK 版，不适用其他游戏变体的 DLL。

使用 GameAPI 替代重复 TalkScene／ActionScene 查找；使用 EventUtils 替代私有 ADV 启动与角色绑定构造，保留同步启动异常及 Bridge 等待时序；使用 GameExtensions 的光标及班级座位辅助。原生 AI、保存过滤、控制权／恢复、ADV 等待与输入、触碰／菜单及精确时间 Hook 在不等价处保留。详见[迁移评估](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/KKAPI-MIGRATION.md)。

继续兼容 .NET Framework 3.5、C# 3，保留警告视为错误和公开引用依赖锁定。CI 增加生产报告模块的生命周期／快照测试。安装 ZIP 附带依赖说明，不打包第三方或游戏 DLL。

## 验证与限制

干净环境锁定还原、net35 编译与打包通过；106 项报告断言、12,414 项辅助接口等价性断言、20 项 JSON 断言和 37 项产物检查通过。实机通过全部九套现有验收（93 项）、127 项补充回归，以及普通／桥接角色单人、女性双人、三人、非零重叠计数、延后属性结算、中途退出和切档等 H 测试。[迁移评估](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/KKAPI-MIGRATION.md#200-release-validation) 区分模拟测试与实机验收，并列出仍需按安装环境验证的场景。

采集范围是原生 HProc 会话；没有触发此生命周期的后台 AI 动画不在范围内。原生未提供的分角色高潮／结束次数、独立男性高潮总数、KKAPI 开始前的过程及未观测到的后台事件均不猜测。属性差值仅说明实际观测变化，也可能包含其他 Mod 的修改。

## 安装

关闭游戏，安装[官方 KKAPI](https://github.com/IllusionMods/IllusionModdingAPI/releases/tag/v1.48.1) 与 [BepisPlugins 依赖](https://github.com/IllusionMods/BepisPlugins/releases)，再替换 `BepInEx/plugins/KK_StoryNPCBridge.dll` 并重启。ZIP 包含该 DLL、MIT 许可证及 `DEPENDENCIES.md`；`SHA256SUMS.txt` 提供下载校验值。升级时请一并备份故事存档和对应的现有 Bridge profiles。
