# KK_StoryNPCBridge 1.5.0

English | [简体中文](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.5.0/docs/releases/1.5.0.zh-CN.md)

Changes since **1.4.0**.

## Added

- `play_adv_motion`: an independent native `ADV.CharaMotion` operation in the bridge NPC's ready TalkScene. Supports state/controller resources, native IK data and shake/body-shape data on layer 0, with a configurable 0.1–30 second native delay. Uses the existing ADV sequence lifecycle rather than a second dialogue system.
- `adv_motion_catalog`: inspect installed motion resources, verify compatible state names with the real Animator, and reuse returned motion objects or complete request templates. Missing assets, mismatched IK/shake states, partner-dependent IK and unsupported fields are rejected before execution.
- Advanced motion reports use the existing sequence status, cancellation and lifecycle events, identifying `operation='play_adv_motion'`. Completion includes actual staged controller/clips, IK and physical flags plus restoration status. Disconnect recovery pauses progression without replay; completion, cancellation and native execution failure restore the captured visual state.
- Read-only `actor.clothing`, `clothing_status` and `clothing_catalog` expose the current native clothing coordinate type and explain unavailable observations in roaming and native talk.

## Changed

- Controlled NPCs now participate in native stage-based placement and clothing initialization when the game changes time phases. They then hold at the newly selected native destination, keep ownership/recovery, and report relocation plus cancellation of old movement, tasks and follow bindings. Ordinary player map changes do not relocate the NPC.
- Bridge character progress and activity journals now save **only after a successful native story save**, including native autosaves. Save As writes the actual destination slot. Attribute/expression edits, dialogue return, time changes, handover, periodic sampling and shutdown no longer independently write bridge sidecars; unsaved changes are discarded on reload/exit. Save completion and sidecar failures have separate events.
- ADV reply pagination now measures the actual native font and text rectangle instead of imposing a fixed character count. It handles mixed-width text, oversized words, explicit line breaks and supported rich-text scopes, and reflows remaining pages when native geometry/typography changes. Events report actual display text and layout revisions while history retains the original full reply.
- The manual client and English/Chinese API/reference documentation cover the new motion operation, its resource catalog, restoration, and the distinction from lightweight `Animator.Play` playback.

## Motion support limits

`play_animation`, the dynamic `animation_catalog`, ordinary sequence motions, `say`, `say_native` and native gameplay actions retain their existing roles. Advanced motions are visual and do not create props, partner characters or gameplay effects. Native activity triggers must wait for or cancel a running advanced motion.

Advanced motions use the current camera and placement without automatic reframing. Sitting/lying or event-specific poses can be partly outside the frame in a standing TalkScene; callers need suitable staging for those poses.

Only layer 0 is exposed. `OverrideBundle` / `OverrideAsset` remain unavailable: creating an override controller was observed, but actual clip replacement was not verified. Nonzero/multiple layers are also unavailable. Discovery is intentionally reported as incomplete; callers can validate additional known state names. See the [API parameter table](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.5.0/API.md#advanced-native-adv-motions).

## Validation

Built against both installed game references and locked public compile-time references with warnings treated as errors. Live game checks covered real controller/IK/physics changes and restoration, reusable catalog requests, invalid inputs, ownership, legacy animation, cancellation, disconnect/resume, injected native execution failure, native conversation exit and roaming behavior. Pagination, clothing observation and native time-phase placement received regression checks.

## Installation

Replace `BepInEx/plugins/KK_StoryNPCBridge.dll` while the game is closed, then restart. The ZIP contains that DLL in its installation path plus the MIT license. Download checksums are in `SHA256SUMS.txt`; no dependency or game assemblies are included.
