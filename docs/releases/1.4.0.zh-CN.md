# KK_StoryNPCBridge 1.4.0

[English](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.4.0/docs/releases/1.4.0.md) | 简体中文

相对于 **1.3.0** 的更新。

## 新增

- `play_adv_sequence`：一次提交 1–32 个有序片段，组合 NPC／玩家台词、旁白、表情、已加载动作和延迟。通过现有对话生命周期、菜单协调及分页机制执行一组连续的原生 ADV 指令。
- `adv_sequence_status`、`cancel_adv_sequence` 及进度、完成、取消、原生执行失败事件。意外断线时暂停推进和原生延迟，恢复后不重放已完成片段；取消或切场景会丢弃剩余片段。
- 原生脸红（`blush`）、泪水等级（`tears`）、视线模式（`gaze`）、眼睛高光（`highlight`）和眉毛开合（`eyebrowOpen`）控制，提供实际值、范围及不可用原因。
- `expression_presets` 和 `expression_catalog.presets`：提供 `neutral`、`smile`、`shy`、`crying`、`angry`、`surprised`。通过 `set_expression.changes.preset` 传入语义 key 或返回条目，可显式覆盖单个参数。模式按当前模型的形变标签解析，不使用固定数字 ID；不可用或有歧义的组合会被拒绝。
- ADV 演出片段支持扩展表情对象和预设，使用原生 CharaExpression 及可选 CharaFixMouth 命令。实际显示的台词保留准确的 NPC／玩家／旁白身份和会话归属。

## 调整

- `mouthOpen` 恢复可写，含义为原生张开**上限**。独立的 `mouthFixed` 布尔值显式固定嘴部到该张开度，false 恢复原生运动和口型同步；只设置上限不会自动固定嘴巴。
- 表情参数整批验证后再应用。实时目录提供支持的视线引用、参数可用性和可复用请求，角色回复上报原生实际值；缺少着色器、控制器或必需泪水网格时明确说明，不提供模拟效果。
- 额外表情覆盖随各故事档案保存。清除表情或释放控制会恢复捕获的原生额外参数，包括嘴部固定状态。演出临时修改的额外参数在完成／取消后恢复，原生活动接管时保留其场景管理权。
- 中英文 API／编号参考文档和手动客户端命令补齐演出、预设及扩展表情控制。`say`、`say_native`、直接模式选择和普通原生事件保留原有职责。

## 使用限制

演出要求桥接角色已经进入就绪的原生 TalkScene，可先使用 `native_talk` 或普通交谈。动作使用当前加载的 Animator，切换视觉场景后应刷新引用；不提供任意 ADV 命令或动画包加载。

`tears` 是 `0–3` 的整数等级，不是连续量。视线支持原生 `FORWARD`、`TARGET`、`AWAY` 模式，使用当前原生目标；不提供任意方向、角度或新目标坐标，原生 `CONTROL` 模式明确不可用。脸红遵守游戏中的脸红设置。

传输协议仍为版本 `2`。关闭游戏后替换 `BepInEx/plugins/KK_StoryNPCBridge.dll`，或将 ZIP 解压到游戏目录。请求结构、状态／事件和示例见 [API 文档](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.4.0/API.zh-CN.md)。
