# KK_StoryNPCBridge 2.0.0

English | [简体中文](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/releases/2.0.0.zh-CN.md)

Changes since **1.5.0**. Bridge protocol remains **2**; existing commands, dedicated NPC identity, native-save isolation and control recovery remain compatible.

## H scene reports

- Read-only `status.hScene` and `status.lastHScene`, also available in `list` and subscribed snapshots. Existing `AddEvent` publishes `game_h_started`, `game_h_ended` and exactly one `game_h_completed` for each observed native session.
- KKAPI `GameCustomFunctionController` supplies native start/end objects. Reports include a unique session, participant slots and native-reference identities, game time, modes, unscaled duration, all 46 `HFlag.Count` fields (including sparse mouse-action flags), native end state and character attributes before/native-end/after settlement.
- Counters keep their native scope. Cumulative character values are separately differenced; group counters are never assigned to an individual NPC. Normal NPCs, solo/lesbian scenes and unresolved extra male models cannot impersonate `bridge:main` or create a phantom participating player.
- End callbacks precede final rewards. Statistics are frozen before unload; final attributes wait until H/result scenes have left and normal story resumes. Interrupted scenes, duplicate callbacks, save/generation changes and missing/nonfinite data have explicit unavailable states.
- One passive `HActionBase.SetPlay` postfix counts deduplicated solo/lesbian `Orgasm` state entries, because those controllers do not maintain ordinary H orgasm counters. No duplicate lifecycle hook, scene-discovery polling, unbounded history or gameplay control is added.

[Field meanings, native ranges, mode applicability and unavailable values](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/API.md#read-only-h-scene-reports) and a [complete synthetic JSON report](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/examples/h-scene-report.json) are documented in English and Chinese.

## KKAPI dependency and code reduction

Official **KKAPI 1.48.1 or newer is required**. Install the KK Modding API package and its ExtensibleSaveFormat dependency before the bridge. BepInEx enforces `marco.kkapi >= 1.48.1` and loads it first. Use the KK build, including for patched Party; other game variants are incompatible.

GameAPI replaces repeated TalkScene/ActionScene discovery; EventUtils replaces private ADV startup and heroine-binding construction while preserving immediate startup errors and bridge wait timing; GameExtensions supplies cursor and class-seat helpers. Native AI, save filtering, ownership/recovery, ADV wait/input, touch/menu and exact time hooks remain where KKAPI does not provide equivalent behavior. See the [migration assessment](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/KKAPI-MIGRATION.md).

.NET Framework 3.5, C# 3, warnings-as-errors and locked public compile references are retained. CI also runs the production report module's lifecycle/snapshot tests. The installation ZIP includes dependency instructions and excludes all third-party/game DLLs.

## Validation and limits

Clean locked restore, net35 builds and packaging passed; 106 report assertions, 12,414 helper-equivalence assertions, 20 JSON assertions and 37 artifact checks passed. Real-game validation passed all nine available acceptance suites (93 checks), 127 additional regression checks and H cases covering ordinary/bridge solo, female pair, three participants, positive overlapping native counters, deferred attribute settlement, interruption and save switching. The [migration assessment](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v2.0.0/docs/KKAPI-MIGRATION.md#200-release-validation) separates simulated checks from live acceptance and lists remaining installation-specific scenarios.

The report observes native HProc sessions; background AI animations that never start this lifecycle are outside its scope. Per-participant orgasm/finish counts, an independent male-climax total, activity before KKAPI start and missed offscreen events are unavailable rather than inferred. Attribute deltas describe observed changes, including possible changes from other mods.

## Installation

Close the game, install the [official KKAPI](https://github.com/IllusionMods/IllusionModdingAPI/releases/tag/v1.48.1) and [BepisPlugins dependencies](https://github.com/IllusionMods/BepisPlugins/releases), then replace `BepInEx/plugins/KK_StoryNPCBridge.dll` and restart. The ZIP contains that DLL, the MIT license and `DEPENDENCIES.md`. Download checksums are in `SHA256SUMS.txt`. Back up story saves together with their existing bridge profiles when upgrading.
