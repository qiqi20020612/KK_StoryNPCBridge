# KK_StoryNPCBridge 1.3.0

[English](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.3.0/docs/releases/1.3.0.md) | 简体中文

相对于 **1.2.0** 的更新。

## 新增

- `adjust_stats`：按有符号增量调整原生分数和计数，包括 `favor`、`intimacy`、`lewdness`。按字段合法写入范围限制结果，返回修改前值、实际值、实际增量及受限字段；多属性修改共用现有验证、原生同步、保存和失败回滚流程。
- 增量操作的稳定 `mutationId` 去重机制：同一角色 generation 内重试相同修改会返回首次结果，不会再次累加；恢复控制后也可按原 ID 重试，不同参数复用 ID 会被拒绝。
- `sample_native_action`：每次调用独立随机选择其他原生女孩的当前任务，作为匿名行为参考。返回行动／地图说明及可复用任务请求，不包含来源角色信息；不推进原生 AI，也不消耗游戏随机状态。
- 告白、分手、邀请 H、约会登记和邀请入部的原生事件效果。目录现包含 11 种效果，保留午餐、社团活动、学习、运动、跟随及一起回家。
- 结构化的事件执行条件与执行前后效果快照，包含关系／约会状态及相关原生排行、玩家和社团报告计数。告白、约会登记和入部直接应用成功分支的原生状态效果，无需打开或打断对话。

## 调整

- ADV 台词改用共享宽度额度分页，每页相当于最多 **60 个汉字或 100 个 ASCII 字符**；混合文本共用额度，保留文本元素边界和完整接口历史。
- 嘴巴张开度改为只读，拒绝 `mouthOpen` 写入；插件不再设置张开度上限或固定张开率。嘴型选择仍可修改。
- 原生事件按需明确检查关系、部员、原生时间、约会占用及地点条件；活动流程保留原生 ADV 和游戏效果，跳过邀请／拒绝判定。
- `stat_catalog` 标明可增量修改的字段及限制／去重策略。手动客户端新增 `adjust MUTATION_ID favor=4 intimacy=-2 lewdness=4`；中英文 API 和编号参考文档补齐新操作及返回值说明。

## 接口说明

`set_stats` 保留绝对赋值语义及现有关系／标志含义，未加入情绪评分规则，也不会将满值好感转加亲密度。`adjust_stats` 要求已接管角色、当前 generation、`mutationId` 和 `deltas`，去重记录仅保留在该角色 generation 内且有容量上限。传输协议仍为版本 `2`。

关闭游戏后替换 `BepInEx/plugins/KK_StoryNPCBridge.dll`，或将 ZIP 解压到游戏目录。请求结构、范围、错误和重试方式见 [API 文档](https://github.com/qiqi20020612/KK_StoryNPCBridge/blob/v1.3.0/API.zh-CN.md)。
